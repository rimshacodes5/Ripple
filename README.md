# Ripple 💧
> **Small acts. Generous moments. Infinite impact.**

Ripple is a full-stack web application that uses AI to transform your spare time, budget, and unique skills into personalized micro-missions for everyday acts of generosity.

---

## ✨ Features
* **AI Micro-Mission Engine:** Powered by Google's `gemini-3.6-flash` to generate immediate, actionable acts of kindness based on user-defined constraints.
* **Interactive Water Reservoir:** Visual impact tracking tank built with CSS wave animations and `localStorage` state persistence.
* **Resilient Architecture:** Automatic 3-attempt exponential retry handler in Express backend to handle high-demand API spikes seamlessly.
* **Micro-Interactions:** Synthesized Web Audio API water drop sound effects and one-click clipboard sharing.
* **Mission History Log:** Keeps track of your past completed micro-missions across sessions.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Glassmorphism & Custom Keyframe Animations), Vanilla JavaScript (Web Audio API)
* **Backend:** Node.js, Express.js
* **AI SDK:** `@google/genai` (`gemini-3.6-flash`)
* **Deployment:** Vercel
